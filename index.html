01 / ROBOTIC MANIPULATION

EKALAVYA — Vision-to-Action Robotic Arm

A custom object detector running on Raspberry Pi drives physical pick-and-place motion through a Pi–Arduino serial connection and PCA9685 servo driver.

YOLOv8ONNXRaspberry Pi 4ArduinoPCA9685
Perception: custom YOLOv8 detector exported to ONNX and run on Raspberry Pi 4.
Actuation: detections trigger six-servo motion via Arduino and PCA9685.
Observability: Flask MJPEG stream for monitoring the detection-to-motion loop.
Patent: Indian Patent Application No. 202641059188 A.

02 / ROBOTICS SOFTWARE ARCHITECTURE

ROS 2 Modular Vision Pipeline

Reorganising a blocking vision-to-action script into ROS 2 nodes with an action-based interface and configurable launch parameters.

ROS 2 / rclpyActionsURDFRVizLaunch
Architecture: separate vision-inference and arm-control nodes.
Task management: custom action interface with goal, feedback, result and cancellation.
Configuration: camera index, model path and serial port through launch-file parameters.
Robot model: URDF visualised in RViz to inspect joint ranges before hardware testing.
View project repository ↗
03 / GPU SYSTEMS

Adaptive CUDA Multi-Stream Task Scheduler

A GPU scheduling project designed to overlap kernel execution and memory transfers across multiple CUDA streams.

CUDA CStreamsCUDA EventsSchedulingProfiling
Scheduling: least-finish-time heuristic to assign tasks.
Concurrency: kernel execution and memory transfers across streams.
Measurement: CUDA events used to profile task and per-stream timing.
Reported result: load-imbalance ratio approximately 1.009; definition and measurement setup can be added once confirmed.
